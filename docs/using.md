# 쓰는 법

파일 서버입니다. **웹으로도, 탐색기로도 같은 파일을 봅니다** — 한쪽에서 올리면 다른 쪽에 바로 있습니다. 권한도 하나입니다.

계정과 처음 비밀번호는 관리자에게 받으세요. **웹과 SMB(탐색기)의 비밀번호는 같은 것**입니다.

---

## 어디에 무엇이 있나

| | |
|---|---|
| **내 폴더** | 나만 봅니다. 다른 사람은 목록에도 못 들어옵니다 |
| **팀 폴더** | 그 팀에 속한 사람만. 안에서 만든 파일은 **자동으로 팀 것**이 되어 팀원이 고칠 수 있습니다 |

## 웹

브라우저로 주소를 열고 로그인하면 됩니다. 설치할 것은 없습니다.

| | |
|---|---|
| 올리기 | **파일 올리기** 버튼, 또는 창에 **끌어다 놓기** |
| 내려받기 | 파일 이름을 누르면 됩니다 |
| 찾기 | 위쪽 검색창. `Ctrl`(맥은 `⌘`)+`K` 로 바로 갑니다 |
| 즐겨찾기 | 툴바의 **즐겨찾기**. 첫 화면에 모입니다 |
| 다른 폴더로 | 오른쪽 위 **☰** — 갈 수 있는 폴더 목록이 있습니다 |
| 휴지통 | 툴바의 **휴지통** |

### 찾기

검색창은 **두 가지를 동시에** 합니다.

- **지금 보고 있는 폴더**는 글자를 칠 때마다 바로 걸러집니다.
- **그 아래 폴더들**은 잠깐 멈추면 훑어서 "하위 폴더" 항목으로 따로 보여줍니다. 각 결과에 **어느 폴더에 있는지** 같이 나옵니다.

띄엄띄엄 쳐도 찾습니다 — `ㅎㅇㄹ` 로 `회의록`이 나오고, `nts` 로 `notes.txt` 가 나옵니다. 맞은 글자에 색이 들어가니 왜 걸렸는지 보입니다.

> **이름만 봅니다. 파일 안을 뒤지지 않습니다.** 그리고 하위 폴더 검색에는 한도가 있어서, 너무 넓으면 도중에 멈추고 **멈췄다고 말합니다.** 그 표시가 보이면 결과가 전부가 아니니, 더 안쪽 폴더로 들어가서 다시 찾거나 검색어를 길게 쓰세요.

### 공유 링크

파일 옆 **⋯ → 공유 링크 만들기**. 만료 시간과 비밀번호를 정할 수 있고, 만든 링크는 ☰ 메뉴의 **공유 링크**에서 보고 취소할 수 있습니다.

> ⚠️ **URL 자체가 열쇠입니다.** 로그인 없이 열립니다. 링크를 받은 사람이 누구에게 전달하든 막을 방법이 없으니, **사외로 나갈 수 있다고 생각하고** 만료를 짧게 잡고 필요하면 비밀번호를 거세요. 다 쓴 링크는 취소하세요.

## 탐색기에서 쓰기 (SMB)

큰 파일이나 많은 파일은 이쪽이 편합니다.

**Windows** — 탐색기 주소창에:

```
\\<서버주소>\<내아이디>          내 폴더
\\<서버주소>\<팀이름>            팀 폴더
```

**macOS** — Finder에서 `⌘K`:

```
smb://<서버주소>/<내아이디>
```

**Linux**:

```sh
sudo mount -t cifs //<서버주소>/<내아이디> /mnt/darak -o username=<내아이디>
```

자격 증명을 물으면 **웹과 같은 아이디·비밀번호**를 넣으세요.

## 알고 있어야 할 것

### 지운 파일은 휴지통으로 갑니다

**바로 사라지지 않습니다.** 각 폴더의 **휴지통**에 들어가고, 용량도 계속 차지합니다. 되살리려면 휴지통에서 꺼내면 됩니다.

**정말 지우려면 휴지통 안에서 한 번 더 지우세요.** 그건 되돌릴 수 없습니다.

### 덮어써도 이전 판본이 남습니다

같은 이름으로 다시 올리면 **이전 파일이 휴지통으로 들어갑니다.** 실수로 덮어썼어도 되찾을 수 있습니다.

### 동시에 고치면 나중에 저장한 쪽이 이깁니다

두 사람이 같은 파일을 동시에 고치면 **먼저 저장한 사람의 작업이 덮입니다.** 잠금이 없습니다.

덮인 판본은 휴지통에 있으니 되찾을 수 있습니다 — **단, 아래 한 경우는 예외입니다.**

> ⚠️ **탐색기에서 파일을 열어 그 자리에서 저장한 것은 되돌릴 수 없습니다.** 엑셀·한글 등으로 SMB의 파일을 직접 열어 편집하면 서버는 "새 파일이 올라왔다"가 아니라 "있던 파일이 바뀌었다"로 보기 때문에 휴지통에 사본이 생기지 않습니다.
>
> 여럿이 만지는 문서는 **웹으로 올리는 방식**이 안전합니다.

### 백업이 아닙니다

**유일본을 여기에만 두지 마세요.** 휴지통은 실수를 되돌리는 장치지 백업이 아닙니다 — 서버가 통째로 잘못되면 휴지통도 같이 없어집니다.

### 남의 폴더는 안 보입니다

내 폴더는 나만, 팀 폴더는 그 팀만 봅니다. 웹이든 탐색기든 같습니다. **다른 사람에게 파일을 주려면** 팀 폴더에 두거나 공유 링크를 쓰세요.

### 즐겨찾기와 최근 목록은 이 브라우저에만 있습니다

서버에 저장되지 않습니다. 다른 컴퓨터나 다른 브라우저로 가면 비어 있습니다. 파일 자체와는 무관하니 걱정하실 것은 없습니다.

### 비밀번호

처음 받은 비밀번호는 **바꾸세요.** 웹과 탐색기가 같은 비밀번호를 씁니다. 바꾸는 방법은 관리자에게 문의하세요.

---

## 잘 안 될 때

| 증상 | 확인 |
|---|---|
| 로그인이 안 된다 | 아이디는 전부 소문자입니다. 비밀번호는 탐색기에서 쓰는 것과 같습니다 |
| 탐색기에서 "액세스 거부" | 그 폴더에 권한이 없거나(팀에 속하지 않음), 아이디·비밀번호가 틀렸습니다 |
| 파일이 안 보인다 | 지운 것이면 그 폴더의 **휴지통**에 있습니다 |
| 검색해도 안 나온다 | 이름만 찾습니다. "도중에 멈췄다"가 떴다면 더 안쪽 폴더에서 다시 찾으세요 |
| 올리다 멈춘다 | 큰 파일은 탐색기(SMB)가 낫습니다 |
| 공유 링크가 안 열린다 | 만료됐거나 취소된 것입니다. ☰ → **공유 링크**에서 확인하세요 |
